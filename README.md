# 🌱 植物病害辨識系統 Web 應用 Plant Disease Recognition Web App

這是一個 **基於人工智慧深度學習的植物病害辨識網頁服務**，使用者可以透過上傳植物葉片照片，即時辨識植物是否有病害，並提供可能的病害名稱與相關說明。本專案採用現代 AI 模型與簡潔 Web 介面整合，為智慧農業提供一個輕量且實用的工具。

---

## 🚀 功能特色

✔️ 上傳植物葉片圖片並進行病害辨識  
✔️ 使用 AI 模型分析病徵，給出病害類別  
✔️ 提供簡要病害資訊，提升農民與使用者辨識效率  
✔️ 簡潔易用的網頁介面，可直接在瀏覽器操作

---

## 🛠️ 技術架構 & 堆疊

本系統採用以下技術：

### 🧠 AI 模型  
- **TensorFlow / Keras**：負責訓練與推論深度學習模型  
- 模型輸入為植物葉片影像 → 輸出病害分類結果 + 信心程度

### 🖥️ 後端 API  
- **Flask / FastAPI**：建立 REST API 服務，處理圖片上傳與模型推論  
- 可擴展為 Token 或權限控制等功能

### 🌐 前端使用  
- HTML / CSS / JavaScript：提供使用者界面，簡單上傳圖片並顯示結果
- 框架使用: React.js 及 Bootstrap5
- 與後端 API 透過 AJAX / Fetch API 進行互動

---

## 📌 專案動機

植物病害常會導致農作物損失，而傳統辨識方式需要仰賴專業判斷。本系統透過 AI 技術降低辨識門檻，幫助使用者即時掌握植物健康狀態，並促進智慧農業的發展。

---

## 🖼️ 使用方式
1.在首頁選擇植物葉片的圖片檔案

2.上傳圖片

3.等待 AI 模型返回辨識結果

4.顯示病害類別與相關說明

---

## 🧪 模型訓練與開發
#### 此專案的 AI 模型可根據需要 retrain：
1.使用公開植物病害資料集（例如 Kaggle 上的 PlantVillage）進行訓練

2.在 Notebook 中實作資料前處理、模型架構（CNN / transfer learning 等）

3.匯出訓練後的模型檔 (.h5 / SavedModel) 並放到後端供推論使用
